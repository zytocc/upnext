How it works

Three steps to your next game.

  1. 1

    Bring your games together

    UpNext reads your libraries from Steam, Epic, GOG, Amazon, the EA app and Ubisoft Connect into one list.

    Then it looks up each game's genres, length and what players say.

  2. 2

    Say what you're in the mood for

    About an hour, something calm with a bit of story Curate

    Ask in your own words, or start from one of these:

    • A quiet hour
    • A weekend story
    • Co-op night
    • New to me
    • A hidden gem
    • Surprise me
  3. 3

    Pick one and play

    1Unpacking3.5h story · 96% liked it · Steam

    2A Short Hike1.5h story · 98% liked it · Steam

    3Baba Is You12h story · 97% liked it · Steam

    Each pick says why it fits. Press Play to start it.

What's inside

What it does.

Your whole library in one place
Steam, Epic, GOG, Amazon, EA and Ubisoft games in one list, plus any you add by hand.
Details for every game
Genres, tags, length, review scores and what players say, from the stores and game databases.
Picks that fit the request
Ask for a length, a mood or a genre. Rate the picks, or compare two and let UpNext choose.
A taste profile you can read
It learns your favourites, hard nos and habits, and you can see and change all of it.
Other ways to pick
Shelved games worth a second look, hidden gems, and a roll of the dice for one you forgot.
Web, window or command line
Use it as an app, in any browser at home, or from a terminal.

Your AI, or none

Bring the AI you already use.

The suggestions come from an AI you choose and set up yourself. Without one, UpNext still picks from its own ranking.

  • Your Claude or ChatGPT subscription plan, through their command-line tools, with no API key needed
  • An Anthropic or OpenAI API key
  • A model on your own computer, with Ollama, LM Studio, llama.cpp or vLLM

Privacy

Your library stays on your computer.

Everything is kept in a database on your own machine. No accounts, no ads, no analytics, and this site has no trackers either.

  • The AI gets only what the task needs, never your keys, Steam ID, account names or sign-ins
  • The privacy page lists every service it talks to and what each one is sent

Get UpNext

Runs where you game.

UpNext runs on Windows, Linux or a home server, and every other device in the house can open it in a browser or the Android app.

Windows

Windows 10 and 11 · x64 · .msi

An installer that needs no administrator rights. It adds UpNext and UpNext (big screen) to the Start menu. The builds aren't code-signed yet, so SmartScreen asks first: choose More info, then Run anyway.

Download for Windows Install guide for Windows

Debian, Ubuntu, Fedora, openSUSE

.deb · .rpm · x86_64 and arm64

Packages for Debian, Ubuntu, Fedora and the distributions built on them. Elsewhere, use the release's archive or Flatpak. One command installs the right one for your distribution:

curl -fsSL https://upnext.games/install.sh | sh
Download for Debian, Ubuntu, Fedora and openSUSE Install guide for Debian, Ubuntu, Fedora and openSUSE

Arch Linux, CachyOS

PKGBUILD · x86_64 (builds on aarch64)

Each release has a PKGBUILD for upnext-bin and a ready-built package for pacman, for Arch and the distributions built on it, like CachyOS. curl -fsSL https://upnext.games/install.sh | sh installs the pacman package too.

Download for Arch Linux Install guide for Arch Linux

Flatpak

io.github.zytocc.UpNext · x86_64

For any Linux with Flatpak: a single file on the release page that you install with one command.

flatpak install --user ./upnext-<version>-x86_64.flatpak
Download the Flatpak Install guide for Flatpak

Steam Deck

SteamOS 3 · Flatpak · big screen

Install the Flatpak in Desktop Mode, add UpNext to Steam as a non-Steam game with --big-screen, and it opens with the controller layout in Gaming Mode.

Docker

ghcr.io/zytocc/upnext · amd64 and arm64

For a home server or a NAS: the server and web UI, without the app window.

git clone https://github.com/zytocc/upnext && cd upnext
docker compose -f contrib/docker/compose.yaml up -d
docker logs upnext
Install guide for Docker

Android

Android 8 or later · phone, tablet, TV

Use UpNext on your computer from the couch. The app finds your computer on the network, and you allow it once there. Games still start on the computer.

Download the Android app How pairing works

Any other device

Any browser · your home network

Turn on Allow other devices in Settings, and a laptop, tablet or phone in the house opens UpNext in its browser. Each one asks once, and you approve it on the computer.
